# 稳定增强版

只双击 `双击这里启动.command`。

## 新增功能
- 批量导入页面可选择本地链接文件或包含链接文件的文件夹。
- 新增“每1小时”追更。
- 点击加入后立即返回，首次转存由后台3路队列执行，可继续加入下一批。
- 百度和夸克 Cookie 保存于本机 `data/hub/tasks.db`，每次重启自动读取；页面只显示脱敏摘要。
- 首次运行会自动继承同目录下上一份“唯一完整版_20260723”的任务和 Cookie。

本地文件按钮只读取文件中的网盘链接，不会把本地视频或其他文件上传到服务器。

- 本版使用内置百度直连引擎，启动时不下载外部执行器。
- 后台3个工作线程；百度最多同时2个写入任务，夸克最多3个。


## 中文错误提示增强
任务列表只显示易懂中文原因；完整 HTTP 状态码和原始返回保留在“运行日志”中，方便排查。
